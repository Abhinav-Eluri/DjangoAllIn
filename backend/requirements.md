**PACKAGES**
-------------
- **django**: The core Django web framework for building robust, secure web applications.
- **djangorestframework**: Toolkit for building Web APIs on top of Django.
- **django-allauth**: Integrated authentication app with social login and account management.
- **django-cors-headers**: Middleware to handle Cross-Origin Resource Sharing (CORS) headers.
- **django-filter**: Reusable app for filtering querysets, commonly used with DRF.
- **drf-spectacular**: OpenAPI 3 schema generation and documentation for DRF.
- **django-q**: Distributed task queue for running background jobs in Django.
- **django-silk**: Profiling and inspection tool for Django performance analysis.
- **django-storages**: Collection of storage backends (e.g., S3, GCS) for Django file storage.
- **Pillow**: Python Imaging Library (PIL) fork for image processing.
- **drf-stripe-subscription**: Subscription features with Stripe and REST endpoints
- **pytest-django**: Pytest plugin providing Django-specific testing utilities.
